Aree di intervento

Dal tenant cloud al cavo di rete.

Quattro strati che si tengono insieme. Si leggono dall'alto verso il basso, come un rack: si parte dal tenant che usi ogni giorno e si scende fino al ferro che lo regge.

  1. U42

    Cloud e identità

    Azure e Microsoft 365 con Entra ID e Intune: tenant, criteri di accesso condizionale e gestione degli endpoint su flotte Windows, iOS e macOS.

    • Azure
    • Microsoft 365
    • Entra ID
    • Intune
  2. U30

    Automazione

    Provisioning con Terraform, script PowerShell via Graph API, pipeline CI/CD. Meno operazioni a mano vuol dire meno errori, e qui gli errori si pagano in compliance.

    • Terraform
    • PowerShell
    • Graph API
    • CI/CD
  3. U12

    Continuità operativa

    Backup e disaster recovery con Commvault, Veeam e Azure Backup, policy di retention e procedure di ripristino provate su dati reali, non solo documentate.

    Ripristini testati

    • Commvault
    • Veeam
    • Azure Backup
  4. U01

    Ferro e rete

    Server Windows e Linux, virtualizzazione, Active Directory, reti LAN, WLAN e VPN. Il livello dove i guasti accadono davvero, e dove si risolvono.

    • Windows Server
    • Linux
    • Active Directory
    • LAN / WLAN / VPN
